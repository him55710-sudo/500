# 편지와 힌트, 기억 노트

메인 페이지의 크림색 종이와 와인색 포인트를 게임 안의 팝업으로 이어 갔습니다.

- 편지: 원문과 500·오로나민 C·다른 거 단서를 유지했습니다. 편지지, 작은 우표, 현수의 서명, 다시 읽기와 다음 행동 안내를 함께 배치했습니다.
- 힌트: 현재 퍼즐에 맞는 질문을 복사해 현수에게 직접 보낼 수 있습니다. 게임이 메시지를 보내거나 전화를 걸지는 않습니다. 복사를 사용할 수 없는 브라우저에서는 질문을 선택해 수동 복사를 안내합니다.
- 보조 힌트: 작은 실마리 → 한 걸음 더 → 마지막 단서의 세 장을 직접 열어 봅니다. 정답에 가까운 마지막 카드는 별도로 눌러야 보입니다. 세 장 이후 버튼을 비활성화하며, 같은 플레이 세션에서 다시 열면 본 카드가 유지됩니다. 다음 문제는 새 봉투로 시작합니다.
- 기억 노트: 처음에는 빈 페이지, 문제를 풀면 실제 완료한 기억만 번호를 붙여 기록합니다.
- 공통 팝업: 글꼴, 여백, 색, 닫기 버튼, 퍼즐 버튼, 설정 입력을 같은 종이 디자인으로 맞췄습니다. 작은 화면에서는 편지와 옆 안내를 세로로 배치하고 팝업 내부를 스크롤합니다.

## 파일

- `src/story-ui.js`: 편지·힌트·기억 노트의 마크업.
- `src/story-ui.css`: 범위를 팝업으로 한정한 스타일.
- `src/main.js`: 팝업 연결, 단계별 힌트 공개와 질문 복사.
- `src/state.js`: 단계별 힌트 문구. 퍼즐 상태 전환과 정답은 변경하지 않았습니다.
- `tests/story-ui.mjs`: 실제 UI를 통한 힌트 단계·재열기·질문 복사 성공 및 실패·자물쇠·기억 노트 검증. 시스템 클립보드를 건드리지 않도록 테스트 안에서 복사 API를 대체합니다.

로컬 미리보기: http://127.0.0.1:5186/

게임에 들어가 책상 위 편지를 E로 읽습니다. H는 힌트, J는 기억 노트입니다. 이 수정 작업에서는 Vercel 배포나 기존 `dist` 덮어쓰기를 수행하지 않았습니다.
