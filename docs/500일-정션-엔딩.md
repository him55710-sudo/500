## 공간

POSTECH 중앙강당을 배경으로 재구성한 창작 설치 공간. 미로를 9×9칸(18×18m)에서 21×21칸(42×42m)으로 확장했다. 2.8m 높이의 검정·짙은 보라색 벽, 어두운 바닥, 낮은 보라색 조명과 벽 상단 라인을 사용한다. 무대를 12시로 보았을 때 **빨강 모니터는 4시, 파랑 모니터는 10시, 3색 신호등과 제단은 미로 중앙**에 있다. 두 모니터 방은 측면 출입구 하나로 연결되며 각 방과 중앙에 작은 미니언을 하나씩 배치했다. 미로는 막다른 길 14개, 연결된 통행 칸 188개로 구성한다. 양옆 객석과 무대 엔딩 공간은 유지했다. 실제 강당의 실측 복제본은 아니다.

행사명 참고는 [POSTECH 산학협력단 JunctionX Korea 2026 모집 안내](https://aif.postech.ac.kr/kor/support/event.do?articleNo=17521&mode=view)와 [행사 공식 사이트](https://asia.hackjunction.com/). 무대의 중앙강당 설정과 퍼즐은 사용자가 지정했다. 브랜드 제품명은 글자로 표현하고 사진이나 음원은 추가하지 않았다. 화면의 가사와 마지막 편지는 사용자가 제공한 텍스트만 사용했다.

## 플레이 순서 (제작자 정답 포함)

1. 성심당에서 `92500` → 계산대 서랍이 앞으로 나옴 → 작은 열쇠 집기 → 열쇠로 망고시루 보관함 열기 → 케이크 꺼내기.
2. “ㅋㅋ너가 이걸 참 맛있게 먹었었지” → 세 번 맛보기 → USB 집기 → 강당 문이 회전하며 열림 → 강당 입장. 명란바게트 옆 편지 1/3은 계속 수집할 수 있다.
3. 미로 START에서 빨강 방 바닥의 RED 표식까지 최단 경로는 46칸, 진행 방향은 **↑ ← ↑ ← ↑ ← ↑ → ↑ → ↓ → ↓ ← ↓ →** (`ULULULURURDRDLDR`). 무대 쪽이 위이고, 같은 방향으로 연속 이동하는 구간은 한 번만 입력한다. 실제 미로와 암호는 `src/junction-layout.json`을 공유한다.
4. 빨강 모니터에 USB를 꽂은 후 방향키 잠금을 푼다. 가사는 한 구절씩 나오며 괄호 속 색은 숨긴다. **빨강 2회 / 빨강 2회 / 빨강 2회 / 초록 2회**. 한 구절에서 틀리면 그 구절의 두 번 누르기만 재시도한다. 정답이면 계속 솟는 빨강 광선과 신호등 빨강 불.
5. 빨강을 마친 뒤 VICTORY 탄산수와 T.O.P 커피를 각각 집고 쓰레기통에 버린다. 두 개를 모두 넣으면 파랑 모니터가 켜진다.
6. 사용자 제공 신호등 가사의 시간 빈칸에 **3seconds** 입력 → 뒷면에 빨강 **+5**가 적힌 옷 출현 → 직접 들어 올림 → 파랑 광선과 신호등 파랑 불.
7. 미로의 미니언 인형 세 개를 모아 제단에 바친다. 옷의 이름 **8seconds** 입력 → “너는 항상 이 옷을 싫어했어. 난 좋아했는데.... / 나도 이런 안좋은 기억 가지고 싶지 않아.”
8. 현수에게 옷을 입히고 별도의 칭찬 버튼을 누른다. 현수가 혼란스러운 대사를 말하며 쓰러진다. 노랑 불과 광선이 켜지고 세 광선이 중앙으로 합쳐져 아이패드가 내려온다.
9. 아이패드에서 제공된 편지 전체를 읽고 봉투를 연다. 자유롭게 작성한 편지를 현수에게 보내면 기억이 돌아오고 “기억이 돌아왔어! 하영이는 날 사랑해!!!”.
10. 현수가 하영이와 중앙 원으로 이동 → 두 사람 위로 하트가 내려옴 → “사랑해 하영아!” → **500일 방탈출을 완료하였습니다** → **프롤로그 보기** → 사진집 27장으로 만든 추억 필름 → **하영아 사랑해 ♥**. 사진 필름은 `docs/500일-추억-필름.md`에 정리했으며 PC방 단계는 연결하지 않는다.

## 저장과 입력

일반 플레이는 기존 저장 키에 서랍, 열쇠, 케이크, USB, 퍼즐 상태, 모은 인형, 편지 초안 및 엔딩을 저장한다. 기존 성심당 v1 저장은 v2로 옮기며 USB 이야기부터 이어갈 수 있다. 자유 편지는 브라우저 내부의 게임 상태로만 보관하고 게임 속 현수에게 전달한다. 외부 메시지 서비스에 전송하지 않는다. 공백만 있는 편지는 보내지 않으며 정답 문구나 감정 점수로 내용을 평가하지 않는다. 작성한 글은 HTML로 실행하지 않는다.

미리보기는 기존 저장을 덮어쓰지 않으므로 새로고침 후 초안을 간직하려면 일반 이어 하기로 플레이한다. 연출은 일시정지하면 멈추며, 저장한 연출 단계에서 이어 할 수 있다. 완료 후 프롤로그로 돌아가도 저장은 유지한다.

## 재생성과 검증

- 성심당: `blender/add_bakery_drawer.py` → `blender/export_sungsimdang.py` → `node tools/optimize-sungsimdang.mjs`.
- 강당: `blender/build_junction.py` → `blender/export_junction.py` → `node tools/optimize-junction.mjs`.
- 미로 배치 재생성: `node tools/generate-junction-maze.mjs`. 고정 seed, 방의 단일 입구, 경로 길이와 막다른 길 수를 검증한다. 배치 변경 시 Blender와 GLB도 위 순서로 갱신한다.
- 전체 배치 미리보기: `blender/junction-purple-overview.png`, `blender/junction-purple-plan.png`. 수정 전 원본: `blender/day-500-junction-before-maze-redesign.blend`.
- 게임: `src/junction-state.js`, `src/junction-world.js`, `src/junction-ui.js`, `src/junction.css`.
- `node --test tests/*.test.js`: 순서 제한, 오답, 중복 수집, 실제 미로 경로, 저장 검증과 엔딩 단계.
- 개발 서버에서 `node tests/junction.mjs`: 성심당부터 프롤로그 버튼까지 실제 UI 검증. 화면과 결과는 `test-results/junction-*.png`, `test-results/junction-report.json`.
- `npm run build`: 배포용 정적 빌드 생성. 이번 변경은 로컬에 반영한다.
