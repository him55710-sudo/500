## 200일 진행

첫 방 → 기존 롤러코스터 → 어두운 원형 요리방 → 7호선 문제 → 조명 켜짐 → 중앙 마트와 네 요리방 → 네 가지 완성 → 헬로키티 보너스 공주방입니다. 전체 다섯 퍼즐 방 가운데 현재 첫 번째와 두 번째가 구현되어 있습니다.

제작자 정답: **상동 → 신대방삼거리 → 철산**. 사용자가 알려 준 근무 기간 순서입니다. 실제 노선의 역 위치 순서와는 다른 문제입니다. 노선도는 상동~신대방삼거리 구간을 표시합니다. 문제와 선은 자체 발광하는 연두색으로, 전원이 꺼져 있을 때도 보입니다. 정답 전에는 재료 구매와 요리를 진행할 수 없습니다.

| 방향 | 음식 | 핵심 조작 |
|---|---|---|
| 12시 | 원팬 칠리새우 볶음밥 | 새우 물기 제거, 마늘 볶기, 새우 익히기, 소스 계량, 졸이기, 버터 마무리, 같은 팬에서 달걀·채소·밥 볶기 |

마트에서 재료를 하나씩 챙기며, 레시피별 필요한 분량이 가방에서 소비됩니다. 재료 부족·순서 오류·불 세기 오류·소스 계량 오류는 진행을 막되 아이템을 잃지 않습니다. 음식 확대 보기는 마우스로 돌릴 수 있습니다. 밥만 담긴 도시락, 후라이드만 담긴 도시락, 소스 전후 새우, 초콜릿 덩어리와 코팅 전후 빼빼로를 각각 다른 3D 상태로 표시합니다.

배달은 게임 내 연출이며 외부 주문을 보내지 않습니다. 주문 시각을 저장하고 정확히 10초 이후 수령을 허용합니다. 기사는 7초 시점부터 걸어 들어와 10초에 도착합니다. E로 받으면 상자를 앞으로 내밀고 돌아갑니다. 새로고침해도 주문 시각과 수령 여부가 유지됩니다.

## 레시피 참고와 각색

- [가루씨의 쉬림프박스](https://www.10000recipe.com/recipe/6870522): 마늘·새우를 한 팬에서 볶고 케첩·고춧가루·설탕·간장·식초 소스를 입히는 과정을 참고했습니다. 사용자의 볶음밥 요청에 맞춰 새우를 덜고 같은 팬에서 달걀·채소·밥을 볶는 단계를 추가했습니다.
- [달콤스윗맘의 갈릭새우](https://www.10000recipe.com/recipe/6934270): 마늘·버터·액젓으로 볶는 조리법을 작은 칵테일새우 도시락으로 각색했습니다.
- [우리의식탁 초콜릿 중탕 가이드](https://wtable.co.kr/guide/63190): 약 50°C 물과 마른 볼을 쓰는 중탕 방식, 물이 초콜릿에 들어가지 않도록 하는 과정을 참고했습니다. 게임에서는 코팅 초콜릿을 사용합니다.
- [BBQ 공식 메뉴](https://m.bbq.co.kr/menu/menuList_ajax.asp): 황올반+BBQ양념반(닭다리) 구성을 확인했습니다. 게임은 실제 결제·가격·배달 API를 사용하지 않습니다.

과정을 게임 조작 단계로 단순화했습니다. 실제 조리 시간, 온도계와 식품 안전 판정까지 재현하는 요리 교육 시뮬레이터는 아닙니다.

## 제작 파일

- 편집 원본: `blender/day-200-cooking-rotunda.blend`
- 재생성: `blender/build_kitchen.py`
- 배포 모델: `public/assets/day-200-kitchen.glb` (1,294,364 bytes, Meshopt)
- 게임 규칙: `src/kitchen-state.js`
- 레시피·재료·역 이름: `src/kitchen-data.js`
- 3D 표시·배달·문·조명: `src/kitchen-world.js`
- 조리 및 마트 화면: `src/kitchen-ui.js`, `src/kitchen.css`
- 실제 사진과 웹 금고: `src/personal-memories.js`, `src/memory-data.js`

원형 건축과 네 조리대, 식재료 진열대, 음식 단계별 모델, 배달기사 부품은 Blender 원본에 남아 있습니다. 게임의 한국어 표지판, 조명 전환, 문과 인형의 이동, 상호작용은 웹 코드가 추가합니다. 첫 방의 새 사진과 금고도 웹 실행 시 추가되며 기존 첫 방 Blender 원본 자체를 덮어쓰지 않았습니다.

`tests/kitchen-production.mjs`는 개발용 기능 없이 미리보기 입장·7호선·조명·시점 전환·기존 저장 보존을 검증하고, 배포된 사진 다섯 장과 모델의 SHA-256을 로컬 파일과 대조합니다.
