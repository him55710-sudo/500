# 301~400일 — 지옥에서 천국까지, 우리 둘의 중국 여행

2026-09-24 제작. 기존 Three.js 게임에 연결한 플레이 구간이며 Blender 5.2.2 LTS 편집 원본은 `blender/day-400-china-journey.blend`, 재생성 코드는 `blender/build_journey.py`입니다. 기존 작업 파일과 장면은 삭제하지 않습니다.

## 플레이

- 로컬 빌드: `http://127.0.0.1:5178/?preview=journey`
- 개발 미리보기: `http://127.0.0.1:5179/?preview=journey`
- 첫 화면 마지막 장면의 **301~400일 · 중국 여행 미리보기**로 시작합니다. 실제 저장은 덮어쓰지 않습니다.
- 정상 진행은 300일 구출 완료 화면의 **301~400일 · 중국 여행으로** 버튼에 연결했습니다.
- WASD 이동, 마우스/방향키 시선, E 조사, C 게임 속 휴대폰 카메라, H 힌트, Esc 일시정지. 인벤토리에서 카메라·탑승권·컵을 다시 열 수 있습니다.

## 제작자 진행표 — 정답 포함

1. 용암이 흐르는 1층. 책상 휴대폰의 카톡: 현수 “자기야 우리 5.16에 어디가고 싶어?” / 하영 “222.44.444.66.1”. 반복 숫자 사이의 점은 글자 경계입니다. 표준 키패드에는 1=A가 없으므로 **우리만의 단축키 1=A**를 화면에 명시했습니다.
2. `china`로 철창을 엽니다. 이후 현수는 이전 구출방에서 사용한 동일한 캐릭터 모델로 따라옵니다. 감옥의 실제 첨부 사진 아래 다섯 칸이 있고, `meaty`가 컴퓨터 암호입니다.
3. 컴퓨터에는 첨부 2번 입국 서류가 나옵니다. C 또는 화면 버튼으로 하영의 카메라를 켜고, 실제 3D 모니터의 QR을 중앙에 1.3초 맞춥니다. 원래 QR의 외부 목적지에 접속하지 않는 게임 안의 조준 퍼즐입니다. 실제 웹캠 권한을 요청하지 않습니다.
4. 탑승권: YIM HYUNSU / 인천 ICN → 연태 YNT / 2026-05-16 / FIRST / GATE 2F / SEAT 6B. 실제 항공권이 아닌 게임 소품입니다.
5. 작은 계단을 따라 실제 높이 5.8m의 2층 교회로 올라갑니다. 여섯 줄 A/B 좌석 중 6B 아래 육회비빔밥을 집고, 승무원에게 건네야 탑승할 수 있습니다. 다른 좌석과 아이템 없이 건네기는 통과하지 않습니다.
   - 승무원은 프로젝트에 포함된 Quaternius CC0 여성 캐릭터를 바탕으로 남색 유니폼·스카프·모자를 입혔습니다. 현수와 다른 모델이며 Blender 원본에도 반영했습니다.
   - 교회 북쪽 벽의 별도 2F 탑승구: 안내판, 문틀, 손잡이, 양쪽 슬라이딩 문, 탑승교. 식사를 건네면 문이 열리고 직접 문 안으로 걸어 들어가 기내로 이동합니다. 열린 상태는 저장 후에도 유지됩니다.
6. 퍼스트 클래스 여섯 자리 중 자유롭게 선택합니다. 현수는 옆자리에 앉습니다. 상승 시선과 작은 흔들림 후 **활성 플레이 10초**에 도착합니다. 일시정지 및 설정 화면에서는 시간이 멈추며, 모션 설정으로 흔들림을 끌 수 있습니다.
7. 하차하면 높이 4.8m의 도착 단상. 레드카펫을 밟고 계단을 내려가 높이 10m의 붉은 훠궈 홀로 들어갑니다. 현수와 식탁에 앉으면 열 가지 접시가 도는 회전 레일을 이용합니다.
8. 정답은 **소고기, 수박, 당면, 청경채, 치킨**. 오답은 **양지, 취두부, 버섯, 고수, 메추리알**. 서로 다른 메뉴 다섯 개가 필요하며 중복 획득은 불가능합니다. 싫어하는 접시는 현수가 옆으로 밀어 두어 완성 식탁에 포함되지 않습니다. 오답 때문에 진행 불가능 상태가 되지 않습니다. 마우스나 키보드 포커스로 UI 레일을 멈출 수 있고, 3D 공간에서 직접 접시에 E를 눌러도 됩니다.
9. 다섯 접시를 모으면 **함께 식사하기 → 오늘의 여행 이야기 나누기 → ZAGEE 받기 → 천천히 한 모금 마시기 → 컵을 내려놓으며 낯선 소리 듣기 → 뚜껑 열어 확인하기 → 열쇠 꺼내기**로 이어집니다. 장면마다 짧은 묘사와 현수의 대사가 있으며, 플레이어가 행동 버튼을 눌러야 다음 장면으로 넘어갑니다. 컵을 확인하기 전에는 화면과 3D 식탁 모두 열쇠를 보여 주지 않습니다.
   - 중간에 창을 닫거나 식당을 둘러봐도 현수에게 말을 걸어 같은 장면을 이어갈 수 있습니다. 차를 받은 뒤에는 인벤토리의 ZAGEE로도 이어집니다. 각 단계는 저장되며 이전 버전에서 받은 차·열쇠도 유지합니다.
   - 열쇠를 사용하면 금빛 500 문이 실제로 옆으로 열립니다. 완료 화면에서 다음 성심당 구간으로 이어집니다.

- 첨부 5: 객실 통로·창문·상부 수납장 구성 참고. 좌석 등급은 요청대로 둘만 있는 퍼스트 클래스입니다.

## 파일과 검증

- `src/journey-state.js`: 진행 조건, 음식 중복·호불호, 10초 비행, 저장 검증.
- `src/journey-world.js`: 로드, NPC 추종, 실제 높이, 이동 충돌, 용암 흐름, 회전 접시와 카메라 조준.
- `src/journey-ui.js`, `src/journey.css`: 카톡, 암호, 탑승권, 카메라, 승무원, 음식, 컵.
- `src/journey-ticket.js`, `src/journey-ticket.css`: 노선·승객·날짜·2F/6B 단서가 구분된 탑승권, 현재 단계 및 탑승 상태, 작은 화면 레이아웃. T 또는 인벤토리에서 다시 열 수 있습니다.
- `blender/journey_attendant.py`: 기존 CC0 여성 모델을 승무원으로 변환. 출처는 `public/assets/journey/CREW-LICENSE.txt`에 기록했습니다.
- `tests/journey-state.test.js`: 순서, 오답·중복 복구, 잘못된 저장 방어.
- `tests/journey.mjs`: 실제 UI 자동 플레이, 비행 일시정지, 미리보기 저장 보호, 이어 하기.
- `tests/journey-boarding.mjs`: 여성 승무원·전용 문, 데스크톱/390px 탑승권, 문 개방 저장 복원, 실제 통과 및 탑승 후 표시 검증.
- `/?preview=boarding`: 기존 저장을 바꾸지 않고 2층 승무원·탑승문·탑승권부터 확인하는 미리보기.
- `/?preview=hotpot`: 기존 저장을 바꾸지 않고 훠궈 메뉴 선택부터 식사·대화·차·열쇠 발견 흐름을 확인하는 미리보기.
- `src/journey-story.js`, `src/journey-story.css`: 식사와 컵 발견 장면의 문구·표현. `tests/journey-pacing.mjs`는 장면 유지, 다시 열기, 저장 복원, 모바일, 열쇠의 단계별 발견을 확인합니다.
- `test-results/journey-report.json`: 자동 플레이 결과. `journey-*.png`는 각 단계 화면 기록.

재생성 후 `node tools/optimize-journey.mjs`, `node --test tests/*.test.js`, `node tests/journey.mjs`, `node node_modules/vite/bin/vite.js build` 순서로 검증합니다. 400일 새 구간은 로컬 빌드에 포함하며, 공개 Vercel 사이트에는 이번 작업에서 배포하지 않았습니다.
