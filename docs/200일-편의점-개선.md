# 200일 방 — 편의점과 네 방향 조리방

2026-09-24. 7호선 순서, 네 가지 요리, 10초 배달과 다음 방 연결을 유지하면서 중앙 마트를 확장했다.

- 원형 홀 지름 32m → 44m. 걷기 경계 반경 21.3m.
- 양면 4단 진열대 3줄, 냉장 쇼케이스 2대, 새우 냉동고, 과일·채소 매대, 계산대와 장바구니.
- 외부 3D 원본 45종으로 475개 메시 상품 진열. Kenney Food Kit의 CC0 모델과 Poly Haven의 실제 사과 스캔을 사용했다.
- 장보기 재료 54종. 코너별 진입, 검색, 수량별 담기와 반납을 지원한다. 추가 간식은 선택 사항이다.
- 조리대 불 세기에 맞춘 파란 가스 불꽃, 작은 빛 변화, 상승하는 김과 지글거리는 소리. 불을 끄면 불꽃은 사라지고 김은 서서히 잦아든다.
- 조리 UI에서 현재 조리 단계의 회전 가능한 3D 모형과 실제 음식 사진을 전환한다. 각 요리방 벽에도 참고 사진이 걸려 있다.
- 사진은 실제 음식의 형태 참고 자료이며 게임 레시피의 정확한 완성 사진이나 BBQ 공식 사진으로 표시하지 않는다. 저자와 라이선스를 화면에 표시한다.

## 소스와 재생성

Blender 편집 파일: `blender/day-200-convenience-market.blend`.
기존 `day-200-cooking-rotunda.blend`는 보존한다. 새 파일은 상품이 각각 편집 가능한 상태이며, 게임으로 내보낼 때만 재질별로 합친다.

1. `node tools/fetch-market-assets.mjs` — 다운로드 출처와 파일 기록. Kenney 원본 ZIP은 `external/kenney-food/`에 압축 해제되어 있어야 한다.
2. Blender 5.2에서 `blender/build_kitchen.py` 실행. 공간과 진열은 `blender/market_shelves.py`.
3. `node tools/optimize-kitchen.mjs` — 게임 GLB 중복 제거와 Meshopt 압축.

최종 게임 GLB는 약 2.64 MB. 외부 원본 보관 폴더는 배포 대상에서 제외한다. 사진 4장은 합계 약 0.61 MB.

## 확인

`pnpm test`, `node tests/market.mjs`, `node tests/kitchen.mjs`, `node tests/kitchen-production.mjs`.
마트 브라우저 검사는 통로 이동, 선반·외벽 충돌, 검색/카테고리, 담기/반납, 사진·저작자 링크, 불 세기 전환과 브라우저 오류를 확인한다.
관찰한 진열대 시점에서 70 draw calls / 약 7.4만 삼각형. 이 수치는 해당 시점의 렌더 통계이며 모든 기기의 프레임 속도를 보장하는 수치는 아니다.

3D 식재료 출처: [Kenney Food Kit](https://kenney.nl/assets/food-kit), [Poly Haven Food Apple 01](https://polyhaven.com/a/food_apple_01). 네 요리 사진은 사용자가 직접 제공했다. 파일별 설명은 `public/assets/food-reference/CREDITS.md`와 `docs/market-references/photos.json`에 기록했다.
