# 음식 사진 개선 — 2026-09-24

## 반영 범위

문제 6의 고기 부위 선택 화면을 여섯 장의 사진형 카드로 바꿨습니다. 사진은 먼저 보이고, 부위 이름은 덮개를 한 번 눌러야 보입니다. 다시 누르면 해당 부위에 고기 모형을 놓는 기존 규칙을 실행합니다. 오답으로 고기를 잃지 않는 기존 동작을 유지합니다.

문제 7의 스테이크 기호를 서로 다른 두 접시의 사진풍 음식 이미지로 교체했습니다. 두 접시를 모두 시식한 뒤에만 투표할 수 있는 규칙은 그대로입니다. 이 이미지는 현수의 실제 요리나 알페로의 실제 메뉴 사진이 아닙니다. 화면과 접근성 설명에도 재현 이미지임을 표시합니다.

이번 변경은 음식 UI와 전용 자산만 다룹니다. 공주방 모델·방 구조·퍼즐 규칙·배포 설정은 수정하지 않았습니다. 다른 3D 소품의 전체 재제작이나 실제 해부학적 부위도 교체까지 완료한 것은 아닙니다.

## 자료와 제작 방식

- 살치살 형태 참고 사진: [Certified Hereford Beef — Chuck Flap](https://www.certifiedherefordbeef.com/cut/chuck/chuck-flap/). 실제 척 플랩 사진의 긴 직사각형 형태, 가늘게 분기하는 마블링과 지방층을 이미지 생성 입력으로 사용했습니다. 참고 원본은 `food-references/chuck-flap-reference.jpg`에 보관합니다.
- 부위 설명 확인: [Beef. It's What's For Dinner. — Chuck Flap/Edge Roast](https://www.beefitswhatsfordinner.com/cuts/cut/44450/chuck-flapedge-roast), [Top Round Steak](https://www.beefitswhatsfordinner.com/cuts/cut/2802/top-round-steak), [Certified Hereford Beef — Tenderloin Steak](https://www.certifiedherefordbeef.com/cut/loin/tenderloin-steak/).
- 생성 방식: Codex 내장 이미지 생성 도구. 외부 원본 사진을 게임용 실사 촬영물이라고 표시하지 않습니다.
- `public/assets/beef-cuts-photo-atlas.jpg`: 3열 × 2행. 안심 / 살치살 / 등심 / 채끝 / 우둔살 / 갈비 순서.
- `public/assets/steak-photo-pair.jpg`: 가정식 / 레스토랑 스타일, 2열 × 1행.
- 생성 PNG 원본은 `docs/food-references/`에 보관하고, 웹에는 JPEG 품질 92로 인코딩한 자산을 사용합니다. 잘라내거나 형태를 추가 가공하지 않았습니다.
- UI: `src/food-art.js`, `src/food-art.css`. `src/main.js`는 음식 화면의 마크업 호출과 이름 덮개 동작만 바꿨습니다.

## 다른 소품에도 적용할 기준

실제 제품의 정면·측면 사진을 먼저 확인하고, 실루엣과 부품 비례부터 맞춘 뒤 재질을 조정합니다. 인형은 얼굴과 손의 형태, 악기는 브리지·현·턱받침, 회전목마는 말·기둥·천막·장식의 연결 구조를 우선합니다. 표면은 봉제 원단·금속·도자기·나무의 거칠기와 미세 질감을 구분하고, 외형을 반복하는 구체를 나열하는 방식은 피합니다. 성능을 위해 정지 소품은 재질 단위로 합치고, 인터랙션이 있는 부분만 별도 노드로 유지합니다.
