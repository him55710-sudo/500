## 조작과 렌더링 변경

- 걷기 2.1 → 3.8 m/s, 달리기 3.5 → 6 m/s, 평상 운반 1.05 → 2.8 m/s. 설정에서 0.8 / 1 / 1.3배 선택.
- 이전의 매 프레임 0.05초 제한을 수정. 최대 0.25초의 경과 시간을 1/60초 이하 충돌 단계로 분할하므로 낮은 프레임에서 이동이 느려지지 않음. 탭 전환 뒤에는 이동하지 않도록 입력 해제.
- 시작 전에는 정지된 포스터만 표시. 게임 시작 시 Three.js와 GLB를 지연 로딩.
- 일시정지·설정·퍼즐 창·숨겨진 탭에서는 방 렌더링 정지.
- 기본 품질은 자동. 성능에 따라 DPR 0.65~1.15 범위 내 조절. 선명도·성능 우선 선택도 제공.
- 매 프레임 갱신하던 그림자와 bloom/composer 제거. 고정된 가구만 1024px 그림자 맵에 처음 한 번 그려 캐시하고, 바닥 접촉 그림자를 단순 투명 메쉬로 보강.
- 광원은 반구광·방향광·중앙 스포트라이트·출구 점광원 네 개. 메쉬 변환·충돌 박스와 HUD 갱신의 중복 작업 축소.
- 인형과 회전목마는 정점 색으로 채색하여 재질별 렌더링 호출을 줄임.

## 재생성

Blender는 별도 백그라운드 인스턴스에서 `--factory-startup --python blender/build_room.py`로 생성합니다. `salon_details.py`가 장식과 새로운 모델을 만들고 `tools/optimize-model.mjs`가 웹용 자산을 최적화합니다. 현재 열린 다른 Blender 문서는 이 빌드로 수정되지 않습니다.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python blender/build_room.py
node tools/optimize-model.mjs
pnpm build
```

AI로 만든 시작 포스터와 천장화는 별도 창작 이미지입니다. 생성 방식과 프롬프트는 `이미지-생성.md`에 기록했습니다.
