# 하영에게 보내는 500일 추억 필름

게임 완료 화면의 **프롤로그 보기**를 누르면 사진 필름으로 이어진다.
직접 미리보기: <http://127.0.0.1:5179/?preview=prologue>
로컬 실행 파일의 빌드 미리보기: <http://127.0.0.1:5178/?preview=prologue>

## 연출

- `프롤로그 사진집`의 27장 전체를 파일 순서(번호 없는 사진 → `_01`부터 `_26`)로 보여준다. 실제 촬영 시각을 추측해 재배열하지 않는다.
- 오프닝 6초 → 사진마다 6.5초 → 마지막 편지 7초 → **하영아 사랑해 ♥**. 자동 재생 분량은 약 3분 9초이며 마지막 화면은 계속 남는다.
- 검은 바탕, 따뜻한 크림색 명조체와 연한 장밋빛. 사진 전체가 보이는 미세한 확대·이동과 1.4초 전환. 사진 아래에 짧은 편지 문장을 배치한다.
- 마지막에는 하트를 선으로 그리고 사랑 고백을 보여준다. 처음부터 다시 보기와 첫 화면으로 돌아가기 제공.
- 재생 버튼을 누르면 직접 만든 오르골풍 선율이 작게 시작된다. 음악 버튼으로 끌 수 있다. 외부 음원은 사용하지 않는다.
- 일시정지, 이전·다음 장면, 방향키, 빈 화면에 포커스가 있을 때 스페이스 재생/정지, Escape 일시정지 지원. 다른 탭으로 이동하면 자동으로 일시정지한다.
- 운영체제의 모션 줄이기를 따른다. 사진 로딩 실패 시 재생을 멈추고 재시도를 제공한다.

## 파일

- `src/memory-film-data.js`: 순서, 사진 설명, 기념 문구, 재생 길이.
- `src/memory-film.js`, `src/memory-film.css`: 재생과 화면 연출.
- `src/memory-film-audio.js`: 브라우저에서 합성하는 오리지널 배경 음악.
- `public/assets/prologue/memory-01.webp` ~ `memory-27.webp`: 원본에서 만든 웹용 사본. EXIF 방향을 반영하고 긴 변을 최대 1920px로 맞춘다. 원본 파일은 수정하지 않는다.
- `tools/prepare-memory-film.py`: Pillow로 웹용 사진 사본을 다시 만든다.
- `tests/memory-film.mjs`: 실제 사진 27장, 순서, 자동 전환, 일시정지, 마지막 화면 유지, 재생·복귀, 모바일 배치, 모션 줄이기, 사진 실패 복구를 검증한다.

사진 필름은 3D 장면을 로드하지 않는다. 게임 저장 데이터를 변경하지 않고, 편지는 게임 안에 저장된 상태로 유지한다.
