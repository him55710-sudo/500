# 방 색감과 조명 보정

2026-09-24. 메인 페이지·편지 UI 대신 실제 플레이 공간의 조명과 표면 색을 수정했습니다.

- 갈색·분홍 안개와 진한 가장자리 음영을 걷어 냈습니다.
- 기존 ACES 톤 매핑을 유지하면서 중립적인 채광과 표면 색을 직접 보정했습니다.
- 음악실 벽·기둥은 밝은 아이보리로, 금장은 샴페인 골드로, 벨벳은 선명한 붉은색으로 조정했습니다.
- 바닥의 짙은 갈색 곱셈 색상을 줄이고 나무결의 법선·거칠기를 조정했습니다. 인형은 도색된 표면의 광택, 금속은 반사광, 천은 부드러운 표면을 유지합니다.
- 공주방은 분홍색 벽·리본·보라색·민트색 소품과 파란 창문을 더 명확히 구분하도록 조정했습니다.
- 여러 물체가 공유하는 재질을 물체 수만큼 반복해서 어둡게 만들던 처리를 제거했습니다.

모델·퍼즐·카메라·이동·렌더 해상도는 변경하지 않았습니다. 신규 광원, 후처리 패스, 블룸을 추가하지 않았습니다.

## 구현

- `src/render-look.js`: 방별 색상과 표면 거칠기·금속성.
- `src/world.js`, `src/heaven.js`: 조명, 톤 매핑, 환경 반사.
- `src/scene-clarity.css`: 플레이 화면 가장자리 음영.

Blender 원본과 GLB는 그대로 두고 런타임 재질을 조정했습니다. 현재 수정은 로컬 프로젝트에 반영했으며 이 작업에서 별도로 배포하지 않았습니다.

## 검증

1280×800 Chrome에서 같은 위치·시선·픽셀 비율 1로 전후 화면을 캡처했습니다.

| 장면 | 수정 전/후 그리기 호출 | 수정 전/후 삼각형 | 조명 |
|---|---:|---:|---:|
| 음악실 | 101 / 104 | 273,641 / 273,677 | 4 / 4 |
| 공주방 | 18 / 18 | 322,462 / 322,462 | 3 / 3 |

음악실의 최종 캡처에는 동시에 진행된 다른 작업의 모델 변경이 포함되어 호출 3개·삼각형 36개가 늘었습니다. 이 색감 작업에서는 모델이나 광원을 추가하지 않았습니다. 같은 렌더러에서 비교한 뒤, 비용이 더 낮게 측정된 기존 ACES 톤 매핑을 유지했습니다.

두 방의 브라우저 런타임 오류 0개. 프로덕션 빌드는 `test-results/color-build`에 생성하여 성공을 확인했습니다. 빌드의 기존 500KB 청크 크기 경고는 남아 있습니다.

- 실제 플레이 캡처: `test-results/look-salon-before.png`, `look-salon-final.png`, `look-heaven-before.png`, `look-heaven-final.png`, `look-dolls-final.png`.
- 캡처 도구: `tools/capture-room-look.mjs`.
- 톤 매핑의 비용 비교: `tools/compare-tone-cost.mjs`. 개발 서버의 자동 새로고침 영향을 피하고 같은 렌더러 안에서 두 방식을 비교합니다.
