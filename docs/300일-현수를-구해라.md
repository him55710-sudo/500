# 201~300일 — 현수를 구해라

기존 200일 요리방의 완료 출구에 연결한 세 번째 장이다. 네 가지 구조를 순서대로 해결하고 현수와 함께 400일 방의 도착 홀에 들어간다. 400일 방의 후속 퍼즐은 이 작업 범위에 포함하지 않는다.

## 실행

- 로컬 새 방 미리보기: `http://127.0.0.1:5179/?preview=rescue` (개발 서버)
- 빌드 실행: `게임 시작.cmd`, 주소 뒤에 `?preview=rescue`를 붙인다.
- 정상 진행: 첫 방 → 롤러코스터 → 200일 요리방 → 현수를 구해라 → 400일 도착 홀.
- 미리보기는 실제 진행 저장을 변경하지 않는다. 정상 플레이의 약, 구입한 옷, 지도 핀, 이름판, 손잡기와 완료 상태는 저장된다.
- WASD 이동, E 조사/전달, V 시점 전환. 지도는 클릭 또는 방향키+Enter로 핀을 놓을 수 있다.

## 제작자 정답

1. 트로피 보관함에서 **문 열기 → 트로피 사이 뒤지기**. ‘대상’이 ‘포진’한 곳의 약을 침대의 현수에게 먹인다. 첫 방의 동쪽 문을 사용하면 문을 통과한 뒤 닫히고 겨울 옷가게에 도착한다.
2. 사진이 있는 22벌 중 **POLO RALPH LAUREN 남색 풀 지퍼 니트 + STUDIO TOMBOY 코트**를 고른다. 계산대 직원에게 두 벌을 건네 결제하고, 나시 차림의 현수에게 준다. 잘못 구입한 옷은 교환할 수 있고 실제 금전 결제는 없다. 옷을 받으면 코트·니트·소매가 표시되고 기뻐한다. 코트는 제공된 정확한 개인 상품 사진이 없어 공식 싱글 오버사이즈 블랙 코트를 참고했다.
3. 구름 메모: “너는 내가 어떤 식당을 가고 싶은지도 모르는구나....” 파란 핀을 **미국 텍사스 주**, 빨간 핀을 **브라질**에 놓는다. 실제 경계 폴리곤으로 판정하므로 미국의 다른 주는 정답이 아니다. **(텍사스) vs (브라질)** 이름판을 챙겨 현수에게 제안한다. 정답 뒤 Texas de Brazil의 실제 식당 사진이 보인다.
4. 밖으로 나가면 일본어 경보와 사이렌이 나온다. 현수 앞에서 E로 **손잡기**, WASD로 함께 이동, 400일 방 문에서 E로 탈출. 혼자 출구를 사용하면 통과할 수 없다. 손을 잡으면 3인칭으로 바뀌고 현수가 따라온다. 마지막에는 두 사람이 400일 도착 홀로 들어간다.

## 소리·연출

일본어 음성 파일: `public/assets/rescue/earthquake-ja.mp3`.

> 緊急地震速報。マグニチュード六点二の強い地震が発生しました。揺れに注意してください。落ち着いて、一緒に避難しましょう。

게임용으로 합성한 일본어 안내이며 실제 방송 녹음은 아니다. 사이렌은 게임 오디오 엔진으로 재생한다. 음량 설정·일시정지에 연동하며 모션 설정을 끄면 지진 카메라 흔들림을 끈다. 겨울 방에는 눈발, 바람에 흔들리는 커튼, 현수의 떨림이 있다.

## 파일과 재생성

- 편집 원본: `blender/day-300-save-hyunsu.blend`. 참조 이미지와 재질을 패킹했다.
- 얼굴 자산 원본: `blender/hyunsu-rescue-head.blend`.
- 방 재생성: `blender/build_rescue.py`, 얼굴 재생성: `blender/build_rescue_head.py`.
- 게임 모델: `public/assets/rescue/rescue-room.glb`.
- 규칙/지도 판정: `src/rescue-state.js`, `src/rescue-map.js`.
- 공간/애니메이션: `src/rescue-world.js`. 화면/일본어 경보: `src/rescue-ui.js`, `src/rescue.css`.
- 모델 압축: `node tools/optimize-rescue.mjs`.
- 단위 검증: `pnpm test`. 브라우저 전체 흐름: `node tests/rescue.mjs`.

게임 모델은 약 12.6 MB이며 한 번 불러온다. Blender는 5.2.2 LTS에서 재생성·저장·렌더했다. 기존 첫 방과 200일 방의 원본 씬을 삭제하거나 덮어쓰지 않는다.

## 검증 결과

- `pnpm test`: 23개 통과. 약/옷/지도/탈출 순서, 오답 처리와 실제 지리 경계 검증 포함.
- `node tests/rescue.mjs`: 200일 완료 출구부터 400일 도착까지 8개 검증 항목 통과, 브라우저 오류 0개. 약·결제한 옷·이름판·손잡기 상태에서 새로고침한 뒤 이어 하기 확인.
- `pnpm build`: 성공.
- `node tests/rescue-production.mjs`: 실제 빌드의 진입·시점·힌트·기존 저장 보호, 상품 사진 22개, 원본과 같은 게임 모델, 일본어 음성 디코딩 확인. 음성 길이 13.128초.
- 결과 JSON과 플레이 캡처: `test-results/rescue-report.json`, `test-results/rescue-production-report.json`, `test-results/rescue-*.png`.
