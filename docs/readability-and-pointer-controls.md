# 안내 문구와 마우스 조작 개선

## 안내 문구

- 첫 방: 액자 아래 문구, 스테이크 이름표, 봉투 글씨를 사물 표면 앞으로 이동.
- 마켓: 문 상태 안내를 문 위로 이동하고, 조리실 제목·사진·캡션의 겹침과 바닥 화살표 방향 수정.
- 현수 구하기: 세계지도와 제목이 천장과 겹치지 않도록 크기 조정. 지도 핀 좌표도 함께 조정. 옷가게 부제 이동.
- 여행: 등받이에 묻힌 좌석 번호를 통로 방향으로 재배치. 계단 안내를 난간 앞으로 이동.
- 성심당: 가격표를 진열대 양쪽 통로로 배치. 주문 수량, 빵 선반, 다음 장소 안내를 별도 판으로 표시.
- 마지막 방: 미로 방향 표지의 방향을 바로잡고 파란 콘솔 제목을 보상 옷 위로 이동.

`readable-signs.js`는 불투명한 바탕과 조명에 영향받지 않는 글자를 사용한다. 깊이 검사를 유지하므로 벽 뒤의 안내가 비쳐 보이지 않는다. 모델 로딩 후 적용하므로 기존 Blender 원본을 다시 내보내도 동일하게 배치된다. 퍼즐에서 의도적으로 숨긴 단서는 유지한다.

## 조작

- 화면 클릭: 포인터 잠금과 시점 조작 시작. 잠긴 동안 커서를 숨긴다.
- F 또는 ⛶ 버튼: 전체화면 전환.
- Tab: 커서 해제 / 시점 조작 복귀.
- 메뉴와 퍼즐: 커서를 해제하고, 닫으면 다시 잠금을 요청한다.
- 잠금이 거부되면 재시도 버튼을 표시한다. 잠금 해제 상태에서 마우스를 움직이는 것만으로는 화면이 돌아가지 않는다. 우클릭 드래그와 방향키도 사용할 수 있다.

## 고기 부위 사진

첫 방의 벽 보드와 부위 선택 카드에 실제 사진 6장을 사용한다. 사진을 프로젝트에 포함하므로 외부 이미지 서버에 접속할 필요가 없다. 원본 주소, 작가, 라이선스는 `public/assets/beef-photos/CREDITS.md`와 게임 안의 사진 출처 항목에 기록했다. 다운로드 스크립트는 `tools/fetch-beef-photos.mjs`이다.
