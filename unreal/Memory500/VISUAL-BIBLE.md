# 음악 살롱 시각 제작 기준

이 문서는 현재 구현을 다른 방에 적용할 때 쓰는 제작 기준이다. 참고 이미지와 같은 사실감을 달성했다는 인증이 아니다. 먼저 동일 카메라 비교와 가까이 걸어가 보는 검증을 통과한 요소부터 재사용한다.

## 유지할 정체성

12×12m 공간, 약 4.9m 높이, 사진·편지·다이얼 상자·음악 인형·회전목마·타일의 의미와 위치를 유지한다. `Letter`, `LockBox`, `MemoryFrame0–3`, `FrameCover0–3`, `MusicCabinet`, `ExitDoor` 등 원본 루트 이름은 후속 상호작용 이식의 기준이다. 사진 덮개는 이 시각 샘플에서 열린 상태로 보여 준다. 퍼즐 상태 연동은 아직 구현하지 않았다.

## 조명

- Lumen GI/반사, DX12 SM6, 가상 섀도 맵. 하드웨어 레이 트레이싱은 사용하지 않는다.
- 창의 넓은 면광원이 주광이다. 창 두 곳에 5900K, 3400/2400lm, 100×180cm를 사용했다. 천장 기구에는 3000K, 2200lm, 65×65cm 면광원을 둔다.
- 벽등은 실제 기구 위치에 3100K, 420lm. 인형 진열장은 선반 아래의 따뜻한 발광 띠와 130lm 면광원이 대응한다.
- 노출 min=max=24로 비교 중 밝기를 고정한다. 현재 프로젝트는 확장 EV100 노출 모드를 사용하지 않으므로 이 값을 다른 프로젝트에 그대로 복사하지 않는다.
- 창 바깥은 2K 방향성 HDRI 배경이다. 외부 건물이나 정원을 실제 메시로 제작한 것은 아니다.
- 광원을 추가할 때 보이는 창·기구·발광 부품과 대응시킨다. 읽히지 않는 인형을 후처리로 숨기지 않는다.

## 재질

- 나무·회벽·직물은 별도 공유 마스터와 인스턴스. 거칠기·노멀 세기·실제 cm 단위 타일 크기를 조정한다.
- 주요 표면과 의자는 2K, 작은 소품은 주로 1K. 현재 4K/8K 텍스처는 필요하지 않았다.
- 바닥은 여섯 목재 인스턴스에 작은 색 차이, 노멀 0.18, 거칠기 배율 1.3을 적용했다. 모든 판재를 같은 반사값으로 만들지 않는다.
- 회벽은 원본 스캔의 강한 얼룩을 25%만 남겨 관리된 크림색 실내에 맞춘다. 낡은 벙커 참고의 얼룩을 음악실에 그대로 가져오지 않는다.
- 원본 인형은 버텍스 색을 보존하고 미세 표면만 보강한다. 책상·상자·문과 동일한 금속/거칠기로 통일하지 않는다.
- 러그는 원래 꽃무늬와 UV를 보존한다. 거칠기 0.90–0.98, 직조 노멀과 얇은 봉제 선을 적용했다. 실제 섬유 실루엣 표현은 남은 과제다.
- 스캔 에셋의 텍스처 이름만 믿지 않는다. 마스크 압축과 샘플러가 맞는지 실제 렌더로 확인한다. 촛불 JPG의 검정 배경은 Additive/Unlit 재질로 수정했다.

## 에셋과 공간 밀도

모서리 반경, 구조물 두께, 연결부, 실제 크기, 물체 간 접촉을 우선 확인한다. 작은 장식의 불필요한 Nanite/충돌 생성을 피한다. 의자·탁자 같은 일반 가구는 실물 기반 에셋으로 교체할 수 있으나 고유한 인형이나 편지를 임의로 바꾸지 않는다.

소품은 사용 행위와 연결한다. 악보·필기 노트·연필은 음악 작업, 읽던 책과 화병은 휴식 공간에 배치한다. 편지와 다이얼 조작 면을 가리지 않는다. 새 책은 두께를 측정해 바로 위에 놓고, 병·편지·상자는 책상 높이 108.5cm에 접촉시킨다. 원본 분리 작업은 대상 영역 밖의 면과 재질을 비교한다.

## 사용 흔적과 후처리

우선 스캔 재질의 결·흠집·색 차이와 접힘/접합부를 쓴다. 큰 벽 얼룩이나 무작위 쓰레기는 추가하지 않는다. 봉투에는 접힌 선, 봉인에는 눌린 테두리를 사용했다. 추후 손잡이·작업면의 제한적인 마모를 근접 카메라에서 검증한다.

블룸은 0.1, 모션 블러는 0. 과도한 심도 효과나 컬러 필터로 형상을 숨기지 않는다. 현재 평가 이미지에는 강한 DOF를 사용하지 않는다.

## 평가와 성능

`Evidence/fixed-cameras.json`의 CAM_A/B/C 위치·회전·화각은 변경하지 않는다. 출력은 1920×1080, 수평 FOV 약 97.1143도다. 상세 카메라는 별도로 표기한다. 촬영 전 카메라를 pilot하고 정상 프레임이 진행된 뒤 캡처해야 시간 누적 그림자의 초기화 노이즈를 피할 수 있다.

RTX 4050 Laptop 6GB에서 실제 프레임 시간, GPU 시간과 로컬 GPU 메모리를 기록한다. 초기 PIE 창은 실제 1912×1082였으므로 1920×1080 측정으로 간주하지 않는다. 최종 측정은 에디터를 닫은 독립 실행, 실제 PNG 1920×1080 픽셀 확인, TSR 85%/100% 비교다. 패키지 빌드 성능과 구분한다. 고정 시각 평가는 100%이며 최종 수치는 `Evidence/standalone-final*-performance.json`과 `VERIFICATION.md`에서 확인한다. 기능 스위치나 평균 FPS만으로 시각 품질을 판정하지 않는다.

다른 방으로 확대하기 전에 레퍼런스와의 남은 차이를 기록한다. 현재 약점은 일부 원본 가구의 규칙적인 형상, 가까운 러그의 얇은 섬유 표현, 제한적인 국소 사용 흔적이다.
