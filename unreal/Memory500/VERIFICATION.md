# 검증 결과 — 음악 살롱

2026-09-25, Unreal Engine 5.8.0, RTX 4050 Laptop 6GB, 시스템 RAM 약 16GB에서 확인했습니다.
범위는 기존 방 하나의 시각 개선과 걷기·시점 이동·근접 관찰입니다. 전체 게임 이식이나 AAA 품질 인증이 아닙니다.

## 실제 화면

[고정 카메라와 전후 비교](README.md), [최종 독립 시각 검토](Evidence/final-visual-review.md).
CAM_A/B/C 위치·회전·수평 화각 97.1143도와 1920×1080 출력은 동일하게 유지했습니다.
웹 비교는 원본 Three.js의 실제 실행, Unreal 기준은 원본 Blender 임포트입니다.
웹이 실행 중 추가하는 그림·사진 등으로 두 기준 장면은 완전히 같지는 않습니다.

반복 검토에서 버텍스 색 누락, 잘못된 PBR 샘플러, 촬영 직후 시간 누적 그림자 노이즈,
촛불의 검은 배경, 책의 방향·선반 접촉, 원본 금장 잔존, 램프 줄의 연결 틈을 수정했습니다.
최종 이미지에서 새 책·식물·램프·병, 직물/목재 표면, 편지 접힘과 다이얼 표기가 확인됩니다.
남은 차이는 얇은 러그 섬유, 일부 밝은 잎의 약한 굴곡, 원본 가구·인형의 단순한 구조,
제한적인 국소 마모입니다. 이를 숨기는 심도 효과나 과도한 컬러 필터는 적용하지 않았습니다.

## 이동과 실행

- 실제 Unreal 플레이 창을 열어 장면을 확인했습니다. WASD 입력과 마우스 드래그에 따른 시점 변화를 관찰했습니다.
- 최종 이동 입력 검증: 이동 속도 220cm/s, 538.87cm 이동 후 벽에서 정지, 마지막 구간 위치 변화 0cm.
  바닥 위·방 내부 유지와 시점 입력에 따른 회전 변화를 기록했습니다.
  [검증 데이터](Evidence/walkthrough-runtime-verification.json).
- 저장소에 옮긴 별도 경로에서 `Open-Unreal.ps1`으로 템플릿을 새로 준비하고 에디터를 시작했습니다.
  Python 설정과 MCP 플레이 실행, 실제 화면, 538.83cm 이동·벽 정지를 재확인했습니다.
- 원본 스토리 루트와 충돌 구조를 유지했습니다. 새 장식 17개에는 불필요한 단순 충돌 형상이 없습니다.
- 사진 덮개는 이 시각 샘플에서 숨겼으며, 편지·다이얼·인형 등은 퍼즐 상태와 연결하지 않았습니다.
- 원본 웹 게임 회귀 테스트 **47/47 통과**, Vite 프로덕션 빌드 통과.
  기존 meshopt decoder 청크의 500kB 초과 경고는 남아 있습니다. 이 작업에서 웹 런타임 코드를 바꾸지 않았습니다.

## 1080p 성능

출력 PNG 헤더에서 실제 **1920×1080**을 확인했습니다. Windows 고해상도 배율 때문에 출력이 작아지던 문제는
`bAllowHighDPIInGameMode=True`로 수정했습니다. 초기 PIE의 1912×1082 측정은 아래 수치에 섞지 않았습니다.

| 설정 | 평균 FPS | 평균 프레임 | p95 프레임 | 평균 GPU | GPU 로컬 메모리 중앙값 |
| --- | ---: | ---: | ---: | ---: | ---: |
| TSR 85% | 47.42 | 21.09ms | 24.43ms | 20.11ms | 3616MB |
| TSR 100% | 38.18 | 26.19ms | 30.09ms | 25.17ms | 3683MB |

각 실행은 시작 위치에서 750프레임을 기록하고 처음 200프레임을 제외한 **550표본**입니다.
스크린샷은 제외 구간의 100번째 프레임에 촬영했습니다. 에디터는 닫았고 Codex는 열려 있었으며,
프레임 제한과 VSync는 측정 중 해제했습니다. 배포용 패키지가 아닌 설치된 엔진의 Development 독립 실행입니다.
이 짧은 정지 시점 측정은 방 전체의 최저 FPS나 장시간 안정성 보증이 아닙니다.
실행 도구의 기본값은 TSR 85%, 최대 60FPS입니다.

85%에서 Lumen 반사 약 1.74ms, 그림자 깊이 약 1.13ms, TSR 약 3.11ms였습니다.
두 최종 실행 로그에서 fatal error, video-memory exhaustion, texture-pool-over-budget 메시지는 발견되지 않았습니다.
에디터 시작 로그에는 엔진 자체 UnifiedErrorTest 진단과 사용하지 않는 촛대 변형 두 개의 Nanite/투명 재질 경고가 남습니다.
화면에 사용하는 촛대는 Nanite가 비활성화되어 있으며 최종 실행에서 불꽃이 정상 표시됩니다.
GPU 메모리 값은 프로세스의 로컬 사용량이며 전체 시스템 VRAM 점유와 구분합니다.

데이터: [85%](Evidence/standalone-final85-performance.json), [100%](Evidence/standalone-final100-performance.json).
CSV에는 재계산에 필요한 수치 열만 남겼으며 시작 이벤트와 개발 컴퓨터 메타데이터는 제외했습니다.

## 보존과 배포 범위

원본 추출 폴더 **124개 파일의 SHA256 불일치 0건**, 완전한 웹 기준 체크아웃의 Git 상태도 깨끗합니다.
[최종 원본 검증](Evidence/final-source-verification.json).
Unreal 에셋·텍스처·모델과 비교 이미지는 별도 `unreal/Memory500` 아래 Git LFS로 관리합니다.
엔진 캐시·임시 로그·실행 PID·사용자 참고 사진·Codex 인증 정보는 포함하지 않습니다.
사용하지 않는 Android 파일 서버 설정과 생성된 보안 토큰도 제거했습니다.

Epic 1인칭 템플릿 의존성은 설치된 Unreal에서 `Setup-Templates.ps1`이 준비합니다.
CC0 원본 URL과 해시는 `SourceAssets`의 manifest, 자체 제작 과정은 `Tools`에 있습니다.
새 Blender 소스를 다시 임포트할 경우 램프 연결부가 소스에 포함되므로 기존 `Quality_LampChainLink`
보정 액터를 중복 적용하지 않습니다.
