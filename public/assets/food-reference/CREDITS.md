# 요리 사진 출처

`kimchi.jpg`, `pepero.jpg`, `chili.jpg`, `chicken.jpg`는 사용자가 이 게임 제작을 위해 직접 제공한 실제 음식 사진입니다. 공개 라이선스가 부여된 Wikimedia 사진이 아닙니다. 게임 안에서는 네 요리의 완성 모습 참고용으로 사용합니다.

진열대의 3D 식재료는 [Kenney Food Kit 2.0](https://kenney.nl/assets/food-kit) (CC0), 사과 모델은 [Oliver Harries / Poly Haven](https://polyhaven.com/a/food_apple_01) (CC0)를 사용합니다. 각 모델의 라이선스는 `public/assets/market-icons/LICENSE.txt`에도 기록했습니다.
